Output

The result is one long table, output/tables/spatial_covariates.parquet, written by 21-combine.R. It has 81,000 rows: 1,000 parcels × 81 variables. A CSV copy, spatial_covariates.csv, is written next to it but not committed.

Schema

Column Type Meaning
parcel_id character Parcel ID, P00001 … P01000; joins to data/clean/reference/parcels.parquet
variable character Variable name, one of the 81 below
value double Value, in the unit listed for the variable
source character How the value was obtained: observed, h3_6, h3_5 or oblast

The table is checked before it is written: one row per parcel_id × variable, no missing values, source in the four levels, and exactly 81 variables per parcel.

Read it in R with:

covariates <- arrow::read_parquet("output/tables/spatial_covariates.parquet")

and reshape to one row per parcel, if needed, with tidyr::pivot_wider(covariates, id_cols = parcel_id, names_from = variable, values_from = value).

source levels

Level Meaning
observed Measured directly from the raster or vector data over the parcel. All distance, relief and crop rows, and soil rows where the parcel (or its centroid) has soil data
h3_6 Soil only: filled with the mean over the parcel’s H3 resolution-6 cell
h3_5 Soil only: filled with the mean over the parcel’s H3 resolution-5 cell
oblast Soil only: filled with the mean over the parcel’s oblast (not used in this run)
