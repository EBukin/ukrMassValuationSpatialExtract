Результати

Результат — одна довга таблиця output/tables/spatial_covariates.parquet, яку записує 21-combine.R. Вона має 81 000 рядків: 1 000 ділянок × 81 змінна. Копія у форматі CSV, spatial_covariates.csv, записується поруч, але не зберігається в репозиторії.

Схема

Стовпець Тип Опис
parcel_id character Ідентифікатор ділянки, P00001 … P01000; з’єднується з data/clean/reference/parcels.parquet
variable character Назва змінної, одна з 81 наведених нижче
value double Значення в одиниці, зазначеній для змінної
source character Як отримано значення: observed, h3_6, h3_5 або oblast

Перед записом таблиця перевіряється: один рядок на кожну пару parcel_id × variable, жодних пропущених значень, source в межах чотирьох рівнів і рівно 81 змінна на ділянку.

Прочитати її в R можна так:

covariates <- arrow::read_parquet("output/tables/spatial_covariates.parquet")

а за потреби перетворити на один рядок на ділянку — за допомогою tidyr::pivot_wider(covariates, id_cols = parcel_id, names_from = variable, values_from = value).

Рівні source

Рівень Опис
observed Виміряно безпосередньо з растрових або векторних даних по ділянці. Усі рядки відстаней, рельєфу та посівного покриву, а також ґрунтові рядки, де ділянка (або її центроїд) має ґрунтові дані
h3_6 Лише ґрунт: заповнено середнім по комірці H3 роздільності 6, в якій лежить ділянка
h3_5 Лише ґрунт: заповнено середнім по комірці H3 роздільності 5, в якій лежить ділянка
oblast Лише ґрунт: заповнено середнім по області ділянки (у цьому запуску не використовується)
