Посівний покрив

Сорок дев’ять змінних задають частку кожної ділянки в семи групах земного покриву для кожного з семи років 2019–2025. Скрипти: 06-crop.R (2019–2024) та 07-crop-2025.R (2025).

Змінні

Змінні мають назви crop_<group>_<year>. Кожна — це частка від 0 до 1 класифікованої площі ділянки (без NoData). Для ділянки та року сім часток у сумі дають 1.

ag crop_ag_2019 … crop_ag_2025 Рілля: усі класи сільськогосподарських культур, включно з виноградниками та горіховими насадженнями

Метод, 2019–2024

06-crop.R має окремий блок для кожного року, з роком, записаним повністю. Для кожного року:

  1. читається rast(crop_2019) і задається NAflag(r) <- 0: код 0 означає NoData (фон) у кожному році;
  2. ділянки трансформуються до системи координат карти (EPSG:32636); 10-метрова карта ніколи не перепроєктовується;
  3. exact_extract(r, p, "frac") дає для кожної ділянки частку її класифікованої площі в кожному коді. Кожен 10-метровий піксель зважується за часткою, що лежить усередині ділянки, а пікселі NoData не входять до загальної площі;
  4. коди з’єднуються з crop_groups; коди, відсутні в таблиці, стають "other";
  5. частки підсумовуються за групами, а відсутні групи доповнюються нулями, тож кожна ділянка має всі 7 груп.

Ділянка, що повністю лежить на NoData, отримала б 0 для кожної групи; скрипт виводить кількість таких ділянок для кожного року.

Правило 2025 року: зимова карта має пріоритет над літньою

Для 2025 року є дві карти: літня (усі класи) та зимова, яка позначає лише озимі зернові (2) та озимий ріпак (3). Озимі культури збирають до середини літа, тому літня карта може їх пропустити. 07-crop-2025.R поєднує дві карти:

  • у межах кожної ділянки піксель отримує зимовий код, де зимова карта має значення 2 або 3, і літній код в інших випадках;
  • класи зимової карти, що не є культурами, та NoData зимової карти ніколи не перезаписують літню карту;
  • правило застосовується попіксельно в межах ділянок, ніколи — до всього растра.

Обидва зимові коди належать до ag, тому правило переносить площу з інших груп до ag. У цьому запуску воно змінює частки груп для 135 ділянок.

Дві карти мають однаковий розмір, але їхні точки початку (origin) відрізняються приблизно на 2 м (менше чверті пікселя). Після контрольної перевірки (однакові розміри, точки початку відрізняються менш ніж на 5 м) зимовій карті присвоюється охоплення літньої за допомогою ext(winter) <- ext(summer). Це зіставляє кожен піксель зимової карти з найближчим пікселем літньої без передискретизації. Потім exact_extract() повертає обидва значення для кожного пікселя ділянки разом із часткою його покриття, і частки обчислюються за об’єднаним кодом.

Зведення

Ділянки nodata розміщено у містах, на річках або водосховищі, тому частки забудови та води значно вищі, ніж у типової сільськогосподарської ділянки.

# 06-crop.R
# In:  data/clean/reference/parcels.parquet, crop maps crop_2019 ... crop_2024, crop_groups (from 00-setup.R)
# Out: data/interim/long_crop.parquet
# Purpose: share of each parcel in 7 crop groups, one explicit block per year 2019-2024.

source("00-setup.R")

parcels <- arrow::read_parquet(parcels_path, as_data_frame = FALSE) |> st_as_sf()

# "frac" is the share of the parcel's classified (non-NoData) area in each code.
# 0 is NoData in every year. A parcel entirely on NoData gets 0 for all groups;
# the number of such parcels is printed for each year.

# 2019 ------------------------------------------------------------------------

r <- rast(crop_2019)
NAflag(r) <- 0
p <- st_transform(parcels, crs(r))

crop_long_2019 <- exact_extract(r, p, "frac", append_cols = "parcel_id", progress = FALSE) |>
  pivot_longer(starts_with("frac_"), names_to = "code", names_prefix = "frac_",
               names_transform = as.integer, values_to = "share", values_drop_na = TRUE) |>
  left_join(crop_groups, by = "code") |>
  mutate(group = coalesce(group, "other")) |>
  summarise(value = sum(share), .by = c(parcel_id, group)) |>
  complete(parcel_id = parcels$parcel_id,
           group = c("built", "ag", "forest", "grass", "bare", "water", "other"),
           fill = list(value = 0)) |>
  mutate(variable = str_c("crop_", group, "_2019"))

n_empty_2019 <- crop_long_2019 |> summarise(total = sum(value), .by = parcel_id) |> filter(total == 0) |> nrow()
cli_inform("2019: {n_empty_2019} parcel{?s} entirely on NoData.")

Скрипт: 07-crop-2025.R

# 07-crop-2025.R
# In:  data/clean/reference/parcels.parquet, crop maps crop_2025_summer and crop_2025_winter, crop_groups (from 00-setup.R)
# Out: data/interim/long_crop_2025.parquet
# Purpose: share of each parcel in 7 crop groups in 2025, with winter crops taking precedence over the summer map.

source("00-setup.R")

parcels <- arrow::read_parquet(parcels_path, as_data_frame = FALSE) |> st_as_sf()

# Rule for 2025:
# - the winter map marks winter cereal (2) and winter rapeseed (3);
# - inside each parcel, a pixel takes the winter code where winter is 2 or 3,
#   otherwise the summer code;
# - winter non-crop and NoData never overwrite summer;
# - this is applied per pixel inside parcels, never on the whole raster.
# 0 is NoData in both maps. Shares are of the parcel's classified (non-NoData) area;
# a parcel entirely on NoData gets 0 for all groups, and the count is printed.

summer <- rast(crop_2025_summer)
names(summer) <- "summer"
NAflag(summer) <- 0

winter <- rast(crop_2025_winter)
names(winter) <- "winter"
NAflag(winter) <- 0

if (any(dim(winter) != dim(summer))) cli_abort("The 2025 winter and summer maps have different dimensions.")
if (max(abs(c(xmin(winter) - xmin(summer), ymax(winter) - ymax(summer)))) > 5) cli_abort("The 2025 winter and summer map origins differ by more than 5 m.")

# The winter origin is shifted by about 2 m (less than a quarter of a pixel).
# Giving it the summer extent matches each winter pixel to its nearest summer pixel.
ext(winter) <- ext(summer)

p <- st_transform(parcels, crs(summer))

pixels <- exact_extract(c(summer, winter), p, include_cols = "parcel_id", progress = FALSE) |>
  bind_rows()

crop_long_2025 <- pixels |>
  mutate(code = if_else(winter %in% c(2, 3), winter, summer)) |>
  filter(!is.na(code)) |>
  left_join(crop_groups, by = "code") |>
  mutate(group = coalesce(group, "other")) |>
  summarise(value = sum(coverage_fraction), .by = c(parcel_id, group)) |>
  mutate(value = value / sum(value), .by = parcel_id) |>
  complete(parcel_id = parcels$parcel_id,
           group = c("built", "ag", "forest", "grass", "bare", "water", "other"),
           fill = list(value = 0)) |>
  mutate(variable = str_c("crop_", group, "_2025"))

n_empty_2025 <- crop_long_2025 |> summarise(total = sum(value), .by = parcel_id) |> filter(total == 0) |> nrow()
cli_inform("2025: {n_empty_2025} parcel{?s} entirely on NoData.")

# Long table ------------------------------------------------------------------

long_crop_2025 <- crop_long_2025 |>
  mutate(source = "observed") |>
  select(parcel_id, variable, value, source)

arrow::write_parquet(long_crop_2025, long_crop_2025_path)
cli_inform("Wrote {nrow(long_crop_2025)} rows to {.path {long_crop_2025_path}}.")
